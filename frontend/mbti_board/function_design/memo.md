# 어드민 통계 페이지 아이디어

DB 스키마 기반으로 도출한 통계 항목 목록.

---

## 👤 유저 통계 (`users`, `mbti_test_history`)

| 항목           | 설명                                               |
| -------------- | -------------------------------------------------- |
| 총 유저 수     | 전체 / 상태별(NORMAL, PENDING, LOCKED...) / 역할별 |
| 상태 분포      | 파이 차트 — 정상·대기·휴면·잠금·정지 등 비율       |
| MBTI 분포      | 16개 타입별 유저 수 — 어떤 MBTI가 많은지           |
| MBTI 인증 분포 | TESTED / SELF / DEFAULT 비율                       |
| 로그인 방식    | 소셜 로그인 vs 로컬 로그인 비율                    |
| 가입 추이      | 일별 / 주별 / 월별 신규 가입 수 (라인 차트)        |
| 활성 유저 추이 | 일별 / 주별 마지막 로그인 기준 활성 유저 수        |
| 장기 미접속    | 90일 이상 미접속 유저 수 — `last_login_at` 기준    |
| 탈퇴 배치 삭제 이력 | 날짜별 삭제된 WITHDRAWN 유저 수 — 별도 테이블 필요 (`user_cleanup_logs`) |

---

## 📝 게시글 통계 (`posts`)

| 항목             | 설명                                              |
| ---------------- | ------------------------------------------------- |
| 총 게시글 수     | 전체 / 타입별(FREE·VOTE·DEBATE)                   |
| 타입 분포        | 자유글·투표·토론 비율                             |
| MBTI별 작성 분포 | `author_mbti` 기준 — 어떤 MBTI가 글을 많이 쓰는지 |
| 게시글 작성 추이 | 일별 / 주별 / 월별 (라인 차트)                    |
| 숨김 처리 현황   | `is_visible = false` 비율 및 추이                 |
| 조회수 상위      | view_count TOP 10 게시글                          |

---

## 💬 댓글 통계 (`comments`, `comment_reactions`)

| 항목             | 설명                            |
| ---------------- | ------------------------------- |
| 총 댓글 수       | 전체 / 대댓글 포함              |
| MBTI별 댓글 분포 | `author_mbti` 기준              |
| 댓글 작성 추이   | 일별 / 주별 / 월별              |
| 리액션 현황      | 전체 좋아요 vs 싫어요 수 / 비율 |
| 숨김 처리 현황   | `is_visible = false` 비율       |

---

## 🧪 MBTI 검사 통계 (`mbti_test_history`)

| 항목             | 설명                                                         |
| ---------------- | ------------------------------------------------------------ |
| 총 검사 횟수     | 전체 누적                                                    |
| 검사 결과 분포   | 검사 결과 기준 MBTI 타입별 비율 (현재 유저 MBTI와 비교 가능) |
| 검사 추이        | 일별 / 주별 검사 참여 수                                     |
| 지표별 평균 분포 | EI / SN / TF / JP 평균 점수 히스토그램                       |
| 재검사 빈도      | 1회 / 2회 / 3회 이상 검사한 유저 비율                        |

## 🗳️ 투표 통계 (`vote_posts`, `vote_post_options`, `vote_posts_history`)

| 항목                   | 설명                                |
| ---------------------- | ----------------------------------- |
| 총 투표 게시글 수      | 진행 중 / 마감 구분                 |
| 총 투표 참여 횟수      | `vote_posts_history` 전체 행 수     |
